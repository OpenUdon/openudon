# Result V12 - API-First Browser Fallback

A01 adds local and separately permission-gated static-registry Browsertools
profile discovery, API-first route selection, dependency-aware browser action
frontiers, atomic reviewed materialization, browser-aware intent/UWS/quality
checks, and digest-bound Udon handoff. Profiles and safe review metadata are
package inputs; sessions, credentials, drivers, and raw captures remain outside
OpenUdon. Contributions to the static Browsertools catalog use repository
review, so no membership or mutable registry service was introduced.
