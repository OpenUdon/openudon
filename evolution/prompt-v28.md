# Browser Workflow And Evidence Review Remediation Prompt

Implement the verified iCoT UI and Browser/Playwright review findings without
widening OpenUdon beyond one operator, one workspace, and external trusted
runtime ownership.

The direction-changing requirement is to make an approved browser package
executable through the normal `openudon run` approval/digest gate. Derive all
runtime browser authority from reviewed package facts: driver protocol,
symbolic credential and session mappings, and exact operation/authentication
approvals. Bind the value-free contract into config/evidence and require an
external runner to re-derive it before invoking Udon/Browserdriver.

Close live-authoring containment, nested session-ordering, fail-closed profile
versioning, symbolic-binding, strict review, process-tree, executable TOCTOU,
registry, and atomic-staging findings. Coordinate the producer-side frame/MFA/
human-idle fixes in Browsertools and pin their published revision.

Make browser release evidence prove real authentication with server-gated
sessions and verified MFA values. Reject dirty pinned siblings and compare the
actual Playwright and Chromium versions with one shared compatibility lock.
Preserve honest `not_run`, retain Chromium sandboxing, keep A11.5 pending until
hosted sandbox proof exists, and do not tag or publish v0.2.0.
