# Realistic Playwright-Browser Journey Qualification

The portable Playwright-browser workflow has substantial implementation and
contract coverage, but too few realistic end-user cases. Add a required local
suite of six to eight headless read and write journeys that begins with strict
reviewed Browsertools guided-authoring bundles and crosses OpenUdon import,
UWS synthesis, Udon, Browserdriver, and real Chromium.

Cover ordinary forms, multi-operation navigation, structured reads, approved
and rejected mutations, parameter-boundary failures, and session lifecycle.
Assert exact outputs and server state, keep external network authority absent,
retain no private authoring envelope or page content, and make the suite a
release gate rather than an informational canary. Change upstream repositories
only if a generic owner defect is actually discovered.
