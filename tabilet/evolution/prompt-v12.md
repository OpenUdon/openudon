# Prompt V12 - API-First Browser Fallback

Extend adaptive iCoT authoring and the reviewed package lifecycle to UI-only
workflows without creating a second discovery or execution stack. Prefer
Apitools-backed API operations when they cover the active outcome; otherwise
select a verified Browsertools `uws.browser.1.5` profile, bind one declared
action, and preserve digest, lifecycle, origin, session-posture, and
side-effect approval evidence through trusted Udon handoff.

Browser registry discovery is a static read-only catalog owned by Browsertools,
not a membership service. OpenUdon must not own browser capture, sessions,
credentials, drivers, raw evidence, catalog mutation, or execution.
