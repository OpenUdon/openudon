# v36 — Registration discovery as private authoring state

Separate imperfect website registration discovery from portable registration
recipes. Let the operator record missing routes and registration types in iCoT,
retain private revision history, distinguish coverage from owner review, and
select a route for ordinary reviewed authoring. Reuse one application service
for UI and supervised control. Browsertools owns observations; UWS keeps reviewed
workflow semantics and published optional discovery compatibility. Do not launch
a browser, grant authority, reset consumed attempts or rewrite reviewed profiles
as a consequence of inventory edits or selection.
